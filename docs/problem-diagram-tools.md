# 문제 그림 그리기

> 시험·학습지용 **소재별 그림 생성기**. GeoGebra·알지오매스 같은 범용 작도 프로그램이 아니다.  
> 코드 단일 출처: [`lib/diagrams/catalog.ts`](../lib/diagrams/catalog.ts)  
> 허브: `/tools/figures` · 개별 도구: `/tools/figures/{toolId}`

이후 **문제 그림 도구를 추가하거나 손볼 때**는 이 문서를 먼저 읽는다. 엔진·조작은 **원의 현** (`g3-circle-chords`)을, 스튜디오 **3열 배치**는 **입체도형의 닮음** (`g2-similar-solids`)·히스토그램을 참고 구현으로 삼는다. 1열은 남은 폭을 채우고, 그림 아래에는 모양을 크게 바꾸는 설정(도형 종류 등)을 둔다. 2열은 표시·보기·닮음비 같은 세부 설정. 3열은 **빠른 그림**과 **그림 스타일**만. 수직선·일차부등식의 2열은 가로로 긴 축용 예외이지 새 도구의 기본이 아니다.

---

## 1. 한 줄 요약

한 카드 = 한 소재. 그 소재의 시험 그림을 **그림 위에서 바로 고쳐 PNG로** 뽑게 만든다.

교사가 점·수선·설명선을 범용 작도 순서로 만들지 않는다. 이미 그 유형에 맞춰 점만 끌면 나머지가 따라오게 한다.

---

## 2. 왜 범용 작도기가 아닌가

한국 중등 수학 교사가 시험 그림을 그릴 때 쓰는 대표 도구는 **알지오매스(AlgeoMath)**, **지오지브라(GeoGebra)**, 예전 **가나모그래프**, 한글/파워포인트 그리기 개체다.

공통 불만은 같다.

- 현 하나, 수선 하나, 길이 `x cm` 하나를 넣으려 해도 작도 순서가 길다.
- 설명선(길이 표시 호), 직각 표시, 세리프 수식 폰트를 맞추는 데 시간이 더 든다.
- 원하는 건 “원의 현 문제 그림”이지, 기하 소프트웨어 전체가 아니다.

그래서 이 제품의 도구는 **소재를 나눈 생성기**다.

| 범용 작도기 | 이 도구 |
|-------------|---------|
| 점·선·원·수선을 직접 작도 | 그 소재의 점만 끌면 수선·직각·설명선이 따라옴 |
| 설명선·직각·라벨을 따로 꾸미기 | 고른 대상의 표시 칩 + 그림 위 글자 수정 |
| 학습 곡선이 있음 | 프리셋 → 그림에서 고치기 → PNG |

알지오매스 꾸미기(설명선 `E`, LaTeX 세리프, 직각 네모)와 교과서 그림의 **결과물 스타일**은 따르되, 조작은 훨씬 좁고 얕게 둔다.

## 3. 정보 구조

```
도구 (/tools) 
  └─ 문제 그림 그리기 (/tools/figures)
        ├─ 중1 카드들 → /tools/figures/g1-number-line , /tools/figures/g1-coordinate-plane , /tools/figures/g1-polygon , /tools/figures/g1-circle-sectors , /tools/figures/g1-solid-sketch , /tools/figures/g1-histogram
        ├─ 중2 카드들 → /tools/figures/g2-repeating-decimal , /tools/figures/g2-linear-inequality , /tools/figures/g2-linear-function , /tools/figures/g2-triangle-centers , /tools/figures/g2-isosceles-triangle , /tools/figures/g2-similar-solids , /tools/figures/g2-quadrilaterals , /tools/figures/g2-similar-figures , /tools/figures/g2-similar-triangles
        └─ 중3 카드들
              └─ 원의 현 → /tools/figures/g3-circle-chords
```

- 학년 id는 콘텐츠와 같다: `1 | 2 | 3` ([`lib/grades.ts`](../lib/grades.ts)).
- 도구 id는 **불변 슬러그**. 권장: `g{학년}-{slug}`  
  예) `g3-circle-chords`, `g3-circle-tangents`, `g2-similar-triangles`
- 허브·navbar 등록은 카탈로그만 수정하면 된다. 콘텐츠 시스템(`lib/contents.ts`)·XP·학급 배정과는 **무관**하다. 수업 도구다.

새 도구를 만들 때 파일 위치:

```
lib/diagrams/catalog.ts                    ← 메타 등록 (필수)
lib/diagrams/<toolId>/                     ← 상태, 프리셋, 장면(scene)
components/tools/figures/<id>/             ← 편집 UI (스튜디오만)
app/tools/figures/[toolId]/page.tsx        ← renderDiagramStudio() 분기만 추가
components/tools/figures/DiagramToolShell.tsx  ← 공통 뼈대. 손대지 않음
```

개별 도구 페이지 파일(`app/tools/figures/g3-tangents/page.tsx` 같은 것)을 **만들지 않는다.** 라우트는 `[toolId]` 하나다.

페이지 구성은 항상 같다. 새 도구를 넣어도 **의견은 자동으로** 붙는다.

```
/tools/figures/{toolId}
  └─ DiagramToolShell          ← 공통. 도구마다 복사하지 않음
        ├─ 스튜디오 (도구별)   ← 여기만 새로 작성
        └─ DiagramFeedback     ← 공통 의견. tool_id로 구분
```

## 4. 시험 그림 시각 규칙

모든 도구가 이 규칙을 기본값으로 따른다. 스타일 슬라이더로 미세 조정은 허용하되, 기본값이 시험지처럼 보여야 한다.

1. **흰 배경, 검은 선.** 장식 색·그라데이션·이모지는 그림 안에 넣지 않는다.  
   예외: **좌표평면**은 교과서처럼 연한 청록 격자와 분홍·청록 그래프를 쓴다. **닮은 평면도형**의 모눈은 교과서 모눈종이처럼 연한 청록 격자다. **히스토그램·도수분포다각형**은 막대 채움과 비교 선에 청록·분홍을 쓴다. **일차부등식** 해의 범위는 꺾은선 아래를 연한 분홍 등으로 칠할 수 있다. **순환소수 나눗셈**은 나머지·순환마디를 교과서처럼 분홍·파랑·노란 칸으로 표시한다.
2. **선은 가늘고 일정.** 기본 굵기는 인쇄해도 무너지지 않을 정도만.
3. **수식 세리프.** 변수(`x`, `y`, `a`)는 이탤릭 세리프. **점 이름(`A`, `B`, `O`)은 직립 로만.** 숫자와 단위(`cm`)·한글은 직립.  
   (`16 cm`, `$x$ cm` 가 교과서와 같아야 한다. 점 이름만 기울이지 않는다.)
4. **길이 표시는 설명선.** 선분 옆에 점선 호(또는 짧은 괄호 곡선) + 그 가운데 라벨.  
   알지오매스 “꾸미기: 설명선”과 같은 역할이다. 숫자만 선 위에 덩그러니 두지 않는다.
5. **직각은 작은 네모.** 호나 점 세 개로 직각을 대체하지 않는다.
6. **중심·꼭짓점은 작은 채운 점** + 바깥쪽 라벨. 라벨이 선과 겹치면 드래그로 옮길 수 있게 한다.
7. **비율.** 기본은 입력한 길이가 그림과 맞게. 드래그로 모양을 잡을 때는 대략이어도 된다. 보이는 숫자를 고치면 그때 그림을 다시 맞춘다.
8. **내보내기.** 1순위는 **PNG**(한글·워드·슬라이드에 붙이기). SVG는 있으면 좋다. 화면 미리보기와 다운로드 파일이 같은 장면이어야 한다.

## 5. 편집 UI 원칙 (직관성)

새 도구 UI는 아래 **3열 그리드**를 기본으로 쓴다. 레이아웃 참고: [`SimilarSolidsStudio.tsx`](../components/tools/figures/similar-solids/SimilarSolidsStudio.tsx), [`HistogramStudio.tsx`](../components/tools/figures/histogram/HistogramStudio.tsx). 컨트롤 위젯은 [`components/tools/figures/controls.tsx`](../components/tools/figures/controls.tsx)를 재사용한다.

### 5.1 데스크톱 3열 (필수)

`lg` 이상에서 스튜디오 본문은 **항상** 이 그리드다. 새 도구에서 2열(`1fr` + 오른쪽 패널)을 만들지 않는다. 1열을 `minmax(0,22rem)`처럼 가두지 않는다.

```tsx
<div className="grid items-start gap-5 lg:grid-cols-[minmax(0,1fr)_minmax(14rem,16rem)_minmax(15rem,18rem)]">
```

- 1열 `minmax(0,1fr)`: 2·3열을 뺀 **남은 폭을 그림이 채운다.** (`g2-similar-solids`와 같음). 그림 아래에는 **그림을 크게 바꾸는 설정**.
- 2열 `minmax(14rem,16rem)`: **세부 설정.** 표시 칩·목록·보기. 좁게 둔다.
- 3열 `minmax(15rem,18rem)`: **빠른 그림**과 **그림 스타일만.** 도형·치수·종류를 여기에 두지 않는다.

캔버스 카드. 모바일만 `max-w-[24rem]`. **데스크톱에서는 `lg:max-w-none`으로 1열 전체를 쓴다.**

```tsx
<div className="mx-auto w-full max-w-[24rem] overflow-hidden rounded-3xl border-2 border-wood/10 bg-white shadow-[0_12px_40px_rgba(61,44,30,0.08)] lg:mx-0 lg:max-w-none">
```

1열 그림 **아래**에 계급·축·도형 카드가 있으면 래퍼를 한 겹 더 둔다.

```tsx
<div className="mx-auto w-full max-w-[24rem] space-y-4 lg:mx-0 lg:max-w-none">
  <div className="overflow-hidden rounded-3xl border-2 border-wood/10 bg-white shadow-[0_12px_40px_rgba(61,44,30,0.08)]">
    {/* canvas */}
  </div>
  {/* 그림 바로 아래 설정 */}
</div>
```

| 열 | 역할 | 넣는 것 |
|----|------|---------|
| 1 | **그림 + 큰 설정** | 캔버스가 1열을 채움. 헤더의 PNG·복사·SVG는 그리드 위, 공통. 그림 바로 아래: 도형 종류·밑면 변의 수·치수·그림 종류처럼 **모양을 크게 바꾸는 카드**. |
| 2 | **세부 설정** | 고른 대상의 칩(수선·직각·면 채움·숨은 선·라벨…), 대상 목록·지우기, 보기(회전 슬라이더 등), 닮음비처럼 숫자를 미세 조정하는 칸. 그림을 고치는 스위치. |
| 3 | **빠른 그림 · 스타일** | 빠른 그림(프리셋). **그림 스타일**은 `<details open>`로 기본 펼침(접을 수는 있음). 도형·치수·종류·닮음비는 넣지 않는다. |

카드를 어디에 둘지 애매하면 이 순서로 고른다.

1. **3열:** 빠른 그림, 그림 스타일. 이 둘만.
2. **1열 그림 아래:** 바꾸면 그림이 통째로 달라지는 것. 예) 입체 종류, 다각형 변의 수, 히스토그램 계급·축, 좌표 범위, 삼각형 닮음 종류.
3. **2열:** 나머지 세부. 예) 표시 칩, 보기, 닮음비, 대상 목록.

기존 도구를 손볼 때도 이 열 역할을 맞춘다. 3열에 도형·치수·종류가 남아 있으면 1·2열로 옮긴다.

좁은 화면에서는 같은 순서로 세로 쌓인다(그림 → 큰 설정 → 세부 설정 → 빠른 그림·그림 스타일).

**예외.** 가로로 긴 축이 본체면(수직선·일차부등식)만 2열 `lg:grid-cols-[minmax(0,1fr)_minmax(16rem,20rem)]`을 쓴다. 좌표평면·입체·원·다각형은 위 3열을 그대로 복사한다. 기존 2열 도구를 손볼 때는 3열로 옮기는 쪽을 우선한다.

### 5.2 조작

1. **미리보기는 1열을 채운다.** 데스크톱에서 그림을 `22rem`·`24rem`으로 가두지 않는다. PNG 내보내기 크기는 장면(scene) 해상도다. 큰 설정은 1열 그림 아래, 세부는 2열, 프리셋·스타일은 3열.
2. **값은 그림에서 고친다.** 보이는 숫자·점 이름을 누르면 바로 수정한다. 숫자를 넣으면 그림도 맞춰 바뀐다. `x`를 넣으면 미지수로 표시한다.
3. **끝점은 길이 고정.** (원의 현) 원 위 점을 끌면 반대쪽이 원을 따라간다. 현 가운데를 밀 때만 거리가 바뀐다.
4. **표시는 2열 칩.** 수선, 직각, OA/OB, 중점, 면 채움 등. 목록에서 바로 지운다.
5. **스타일은 3열에서 기본으로 펼친다.** 선 굵기, 글자·점 크기, 저장 배율. 접을 수는 있다.
6. **저장이 항상 보인다.** PNG 다운로드, 이미지 복사. 파일 이름은 한글 소재명. 헤더는 그리드 밖.
7. **프리셋은 시작점.** 3열 「빠른 그림」에서 자주 나오는 그림부터 고른 뒤, 그림 위에서 고쳐 나간다.

## 6. 새 도구 추가 체크리스트

1. [`lib/diagrams/catalog.ts`](../lib/diagrams/catalog.ts)에 `DiagramToolMeta`를 추가한다. `status: "ready"` 전에는 허브에 준비 중 카드로만 둔다.
2. `lib/diagrams/<toolId>/`에 상태 타입, 프리셋(실제 시험 유형 2~4개), `buildScene()`을 둔다.
3. 장면은 캔버스/SVG가 같이 쓸 수 있는 명령 목록으로 만든다. 미리보기와 PNG가 어긋나면 안 된다.
4. `components/tools/figures/<toolId>/`에 스튜디오 UI. **§5.1 3열을 클래스까지 그대로 복사**한다 (`1fr` + `14–16rem` + `15–18rem`, 캔버스 `lg:max-w-none`). 1열을 `22rem`으로 가두지 않는다. 1열 그림 + 모양을 크게 바꾸는 설정, 2열 세부 설정(표시 칩·목록·보기·닮음비), 3열 빠른 그림·그림 스타일(기본 펼침)만. 헤더에 PNG·복사. 수직선·일차부등식처럼 축이 가로로 긴 경우만 2열 예외.
5. [`app/tools/figures/[toolId]/page.tsx`](../app/tools/figures/[toolId]/page.tsx)의 `renderDiagramStudio()`에 `case`만 추가한다. 라우트를 새로 만들지 않는다. 페이지는 반드시 [`DiagramToolShell`](../components/tools/figures/DiagramToolShell.tsx)로 감싼다 — 스튜디오만 `return`하면 의견이 빠진다.
6. 기본 프리셋으로 PNG를 저장해 보고, 라벨 겹침·직각 위치·단위 이탤릭 여부를 확인한다.
7. 이 문서 §8 도구 목록에 한 줄 추가한다. 의견용 마이그레이션·컴포넌트·RPC는 **추가하지 않는다.** 같은 `pm_diagram_feedback`이 `tool_id`로 갈린다.

하지 말 것:

- 3열 1열을 `minmax(0,22rem)` 또는 캔버스 `max-w-[24rem]`(lg에서도)로 가두지 않는다. `g2-similar-solids`처럼 남은 폭을 채운다.
- 범용 기하 캔버스(자유 작도, 도구 팔레트 10개 이상)를 이 허브에 넣지 않는다.
- `lib/contents.ts`에 넣거나 XP를 주지 않는다.
- 기존 콘텐츠 단원 페이지를 이 도구의 진입점으로 바꾸지 않는다. 진입은 `/tools/figures`다.
- 도구별 `page.tsx`를 새로 만들거나, 스튜디오 안에 `DiagramFeedback`를 복사하지 않는다.
- 도구마다 의견 테이블/알림 RPC를 새로 만들지 않는다.

## 7. 참고 구현: 원의 현 (`g3-circle-chords`)

중3 `3.2 원의 성질`에서 나오는 전형적인 그림.

- 원, 중심 `$O$`, 현, 중심에서 현에 내린 수선, 직각, 반지름, 설명선 길이.
- 성질: 수선이 현을 이등분, 같은 거리 ↔ 같은 길이, \( r^2 = d^2 + (\ell/2)^2 \).
- **조작:** 원 둘레를 끌어 현을 그린다. 끝점 드래그는 길이 고정·원 위 회전. 끝점을 더블클릭하거나 중심까지 끌면 OA/OB를 잇는다. 설명선은 끌어서 높이만 바꾸고 끝점을 넘기지 않는다. 글자를 누르면 이름/숫자를 고친다. Delete·목록의 지우기로 현을 지운다.
- 수선·직각·OA/OB 등은 **2열** 칩. 원 반지름·단위는 같은 열. **3열**은 그림 스타일.
- 프리셋(빠른 그림)이 곧 문제 유형의 시작점이다. (이 도구는 빠른 그림이 2열에 있다. 새 도구는 §5.1대로 3열에 둔다.)

### 겨냥도 (`g1-solid-sketch`)

중1 `3.4 입체도형의 성질`에서 나오는 시험용 입체 겨냥도.

- 원뿔+반구·원기둥+원뿔은 높이 또는 모선 중 어느 쪽 숫자를 고쳐도 그림이 맞춰진다.

### 다각형 (`g1-polygon`)

중1 `3.3 평면도형의 성질`에서 나오는 시험용 다각형(삼각형–팔각형).

- **점이 진실 원천**이다. 꼭짓점을 끌어 볼록 다각형 모양을 잡고, 변의 수를 바꾸면 정n각형으로 다시 잡힌다.
- 변을 누르면 길이가 켜지고 다시 누르면 꺼진다. 칩으로 내각·외각(한 변 연장)·대각선을 켠다. 외각 미지수는 교과서처럼 연한 분홍 채움을 켤 수 있다.
- 내각·외각이 90°이면 작은 네모(직각 표시)로 그린다. 그 각을 미지수 x로 두면 답을 숨기기 위해 직각 표시를 쓰지 않는다.
- **숫자 입력(그림 위·2열 칸)** 은 그 각·변만 맞춘다. 이미 숫자로 넣어 둔 다른 각·길이는 유지하고, 나머지 점만 최소한 움직인다. 불가능하면 반영하지 않는다.
- `x` / 직접 입력 / 숨김은 표시만 바꾼다. 모양은 그대로.
- 프리셋: 사각형 한 각, 삼각형 외각, 오각형 내각·외각, 한 꼭짓점 대각선.
- 스튜디오는 §5.1 **3열**: 그림 | 표시·도형 | 빠른 그림·그림 스타일(기본 펼침). 원·부채꼴은 이 도구에 넣지 않는다.

### 원과 부채꼴 (`g1-circle-sectors`)

중1 `3.3 평면도형의 성질`에서 나오는 시험용 원·부채꼴.

- 같은 원 위에 부채꼴 여러 개, 또는 원을 끄고 부채꼴만.

- 면 채움은 연한 무채색. 작은 부채꼴·큰 부채꼴(180° 초과) 모두, 호 설명선은 그 부채꼴의 호를 따른다.
- 글자를 누르면 숫자·`$x$`·`3π`로 고치고, 호·넓이를 숫자로 바꾸면 반지름은 두고 중심각을 맞춘다.
- 조작: 원 둘레를 끌어 부채꼴 추가, 끝점 드래그로 중심각, 채움/호를 끌어 통째 회전. Delete로 삭제. PNG·복사·SVG.

### 히스토그램 (`g1-histogram`)

중1 `4.2 도수분포표와 상대도수`에서 나오는 시험용 히스토그램·도수분포다각형.

- 계급 시작·끝(`ㅁ ~ ㅁ`), 계급 크기(범위의 약수 버튼), 가로·세로축 이름, 세로 최댓값·눈금(도수 2·1뿐 아니라 상대도수 1·0.5·0.1). 시작이 0보다 크면 x축 끊기(물결). 그림 위 제목은 켜고 입력한다. 제목은 네모칸 밖 상단. 축 이름은 좌표평면과 같이 x는 우측하단 우측정렬, y는 좌측상단. 제목·축 이름은 끌어 옮기고 글자 크기를 따로 둔다.
- 막대 또는 중점의 점을 세로로 끌어 도수를 그린다. **히스토그램 ↔ 도수분포다각형**은 같은 도수를 보기만 바꾼다. 다각형의 축 눈금은 히스토그램과 같고, 닫힘점은 첫·끝 계급 경계에서 반 칸 바깥(도수 0)에 둔다. 격자도 같다. 가로 격자는 세로축 눈금에만 긋는다.
- 도수분포다각형에서만 비교 그래프를 하나 더 올릴 수 있다. 같은 계급에 도수·색·이름만 다른 선이 겹친다. 도수 칸 아래에 선택한 그래프의 합계를 보여 준다.
- 프리셋: 습도·일수, 점수 다각형, 학교 A·B 상대도수.
- 스튜디오는 §5.1 **3열**: 그림 아래 계급·축(두 칸씩) | 보기·그래프·표시 | 빠른 그림·그림 스타일(기본 펼침). 가로로 긴 그림이라 1열이 남은 폭을 채우고, 2열은 조금 좁게 둔다.

### 순환소수 나눗셈 (`g2-repeating-decimal`)

### 일차부등식 (`g2-linear-inequality`)

중2 `2.2 일차부등식`에서 나오는 시험용 해의 범위 수직선.

### 일차함수 그래프 (`g2-linear-function`)

중2 `2.4 일차함수와 그래프`에서 나오는 시험용 좌표평면 그래프.

- 중1 좌표평면(격자·축·원점)을 그대로 쓰고, 그 위에 `y=ax+b`와 `x=a`·`y=b`를 여러 개 올린다. 분홍·청록·검정·보라.
- 절편: 축과 만나는 곳에 숫자만 (`7`, `-4`). 점을 끌어 다른 절편은 유지한 채 기울기를 바꾼다. `x=a`는 세로, `y=b`는 가로 직선.
- 격자 한 칸은 정사각형(가로 1 = 세로 1). 눈금 간격은 x·y가 같다.
- 식 칸에 `y=2x+1`, `y=(3/4)x-2`, `x=2`, `y=-3`을 넣고 추가한다. 그림 위 식도 같은 형식으로 고친다.
- 점: 직선 위 점 + 축으로 점선 수선 + 축 숫자. 「점 찍기」로 그림에서 찍는다.
- 기울기 설명: 두 점 사이 가로·세로 주황 화살과 Δx·Δy. 끝점을 직선 따라 끈다. (`x=a`·`y=b`에서는 숨김)
- 평행이동: 같은 기울기 두 직선 사이 빨간 세로 화살. 그래프가 하나면 평행한 직선을 하나 더 만든다.
- 프리셋: 절편, 점의 좌표, 기울기, 평행이동, 여러 그래프, x=a·y=b.
- 스튜디오는 §5.1 **3열**: 그림 아래 좌표평면 | 표시·그래프(조금 좁게) | 빠른 그림·그림 스타일(기본 펼침). 글자·식 기본값은 크게, 슬라이더는 겨냥도와 비슷하게 더 키울 수 있다.

### 이등변삼각형 (`g2-isosceles-triangle`)

중2 `3.1 삼각형과 사각형의 성질`에서 나오는 시험용 이등변삼각형.

- 중1 다각형의 점·각·길이 솔버를 재사용한다. 꼭짓점을 끌면 이등변(AB=AC 등) 모양이 유지되고, 숫자를 넣으면 그 각·변만 맞춘다.
- 등변 표시(빗금 1–3개), 내각·외각, 내각 분홍 채움, 같은 각 호·점 표시.
- 보조선 AD/BE/CF를 동시에 켤 수 있다. 자유·중점·수선·이등분선. 직각 네모, 각 이등분 호, 중점 등분 빗금은 칩으로 켜고 끈다. 잘린 각·부분 길이.

### 외심과 내심 (`g2-triangle-centers`)

중2 `3.1 삼각형과 사각형의 성질`에서 나오는 시험용 외심·내심 그림.

- 꼭짓점을 끌면 외심 `$O$`·내심 `$I$`가 따라온다. 중심은 직접 끌지 않는다. 한 그림에 둘 다 켤 수 있다. 이름은 기본이 외심 `$O$`, 내심 `$I$`다.
- 외심: 외접원, OA·OB·OC, 변마다 수선·발 이름을 따로 켠다. 둔각이면 외심은 밖, 직각이면 빗변 중점. 꼭짓점 직각 네모는 내각이 90°일 때만.
- 내심: 내접원, IA·IB·IC, 변마다 수선·발 이름을 따로 켠다. 접선 길이는 접점으로 나뉜 선분에 설명선.
- 반지름·이등분선이 켜진 뒤 각 조각·선분을 누르면 그 각·길이만 붙는다. 미지수는 연한 분홍 채움.
- 글자를 누르면 숫자·`$x$`·직접 입력. 꼭짓점 내각·밑각(반각)·중심각 숫자를 넣으면 그 값에 맞게 삼각형을 다시 그린다. **길이 값**은 표시 글자와 별개다. 세 변의 길이 값을 바꾸면 그 변만 맞추고 나머지 두 변은 유지한다(각은 따라 바뀜). 밑변 BC는 수평. 중심은 다시 계산한다.
- 프리셋: 외심 밑각·중심각·원주각, 직각삼각형 외심, 외접원·수선, 내심 접선·반각·중심각, 내접원·세 변, 외심과 내심.
- 스튜디오는 §5.1 **3열**: 그림 | 표시 칩·목록 | 빠른 그림·그림 스타일(기본 펼침).

### 사각형의 성질 (`g2-quadrilaterals`)

중2 `3.1 삼각형과 사각형의 성질`에서 나오는 시험용 일반 사각형·평행사변형·직사각형·마름모·정사각형·사다리꼴.

- 중1 다각형의 점·각·길이·설명선과 중2 이등변의 등변 표시·각 채움을 재사용한다. **밑변 BC는 가로로** 두고, 꼭짓점을 끌면 고른 도형의 성질이 유지된다(평행사변형은 항상 평행사변형, 직사각형은 네 각 90°).
- 길이 글자와 설명선(점선 호)은 각각 드래그한다. 변 연장은 꼭짓점·방향별로 여러 곳(DA→A, AB→B 등).
- 대변 길이, 대각·이웃각(분홍·파랑 채움), 같은 각 점·x 표시, 평행 화살, 두 대각선과 교점 `$O$`, 조각 길이 AO·OC·BO·OD, 삼각형 면 채움(△AOB·△BOC·△ODC·△OAD), 평행선 `$l$`·`$m$`.
- 마름모는 대각선 수직(O에 직각 네모). 사다리꼴은 AD∥BC. 각·변 숫자를 넣으면 그 값에 맞게 모양이 바뀐다.
- 프리셋: 대변 길이, 대각·이웃각, 대각선 교점·전체·이등분, 맞꼭지각 표시, 평행·등변, 직사각형 대각선, 마름모, 평행선 사이, 사다리꼴 대각선.
- 스튜디오는 §5.1 **3열**: 그림+도형 | 표시·면 채움 | 빠른 그림·그림 스타일(기본 펼침).

### 평면도형의 닮음 (`g2-similar-figures`)

중2 `4.1 평면도형의 닮음`에서 나오는 시험용 닮은 다각형 쌍.

- 중1 다각형의 점·각·길이 솔버와 설명선(점선 호)을 재사용한다. 왼쪽 도형을 그리면 닮음비에 맞춰 오른쪽이 자동으로 그려진다.
- 오른쪽은 회전(0–360°)·좌우/상하 대칭. 통째로 끌어 위치를 옮긴다. 모눈을 켜면 연한 청록 격자와 격자 맞춤.
- 변을 누르면 길이가 켜지고, 대응변·대응각 칩으로 짝에도 붙인다. 왼쪽 숫자를 넣으면 그 각·변만 맞추고 오른쪽은 닮음으로 따라온다.
- 프리셋: 삼각형 5:4, 삼각형 각·변, 사각형 8:10, 모눈 사각형 1:2 대칭.
- 스튜디오는 §5.1 **3열**(가로로 긴 쌍이라 1열이 남은 폭을 채움): 그림 아래 도형(변의 수·닮음비) | 표시·보기(회전·대칭) | 빠른 그림·그림 스타일(기본 펼침).

### 삼각형의 닮음 (`g2-similar-triangles`)

중2 `3.2 도형의 닮음`에서 나오는 시험용 삼각형 닮음·평행선·중점연결·무게중심 그림.

- 중1 다각형의 점·각·길이 솔버와 설명선(점선 호), 중2 이등변의 빗금·사각형의 평행 화살을 재사용한다.
- 그림 종류: 평행선(DE∥BC), 맞붙은 삼각형, 보조선, 직각삼각형 높이, 나비꼴, 평행선 가로지르기, 무게중심.
- 점을 끌면 제약이 유지되고, **표시된 길이·각 숫자는 실제 값에 맞게 따라간다.** 길이·각을 숫자로 넣으면(그림 위 글자·2열 칸) 그림이 맞춰진다. 변을 누르면 부분 길이가 켜지고, 각은 칩으로 켠다. 미지수는 연한 분홍 채움. 90°는 직각 네모.
- 중점 칩은 t=1/2 고정 + 등변 빗금. 무게중심 G는 직접 끌지 않는다.
- **평행선 DE**(DE∥BC)와 **가로선 l·m·n**(평행선 비)은 선을 잡아 위아래로 옮긴다.
- 프리셋: 평행선 DE∥BC, 맞붙은 닮음, 대응변, 각이 같은 보조선, 직각 빗변·기하평균, 나비꼴, 중점연결, 평행선 비, 무게중심.
- 스튜디오는 §5.1 **3열**: 그림 아래 종류 | 표시 칩·목록 | 빠른 그림·그림 스타일(기본 펼침).

### 입체도형의 닮음 (`g2-similar-solids`)

중2 `3.2 도형의 닮음`에서 나오는 시험용 닮은 입체 쌍.

- 중1 겨냥도 엔진을 그대로 쓴다. 왼쪽 입체 하나와 닮음비 `m : n`만 넣으면 오른쪽이 `n/m`배로 같이 그려진다.
- 같은 카메라·같은 픽셀 스케일. 큰 쪽이 실제로 더 크다. 밑면은 같은 높이에 맞춘다.
- 꼭짓점 이름은 왼쪽 `A, B, …` 다음 글자부터 오른쪽이 이어진다. 도형 이름 `A`·`B`는 칩으로 켠다.
- 높이·모서리 숫자는 어느 쪽을 고쳐도 비를 유지한다. 비를 바꾸면 왼쪽 숫자는 두고 오른쪽만 다시 계산한다.
- 길이 표시(높이·반지름·모서리 설명선)는 왼쪽·오른쪽이 독립이다. 대응하는 변을 같이 켜지 않는다.
- 프리셋: 삼각기둥 3:5, 삼각뿔 A·B, 직육면체 2:3, 원기둥 1:2, 원뿔, 사각뿔.
- 스튜디오는 §5.1 **3열**(가로 쌍이라 1열이 남은 폭을 채움): 그림 아래 도형 | 표시·보기·닮음비 | 빠른 그림·그림 스타일(기본 펼침).

이후 접선, 원주각 등을 넣을 때도 **같은 카탈로그·같은 3열 스튜디오·같은 스타일 규칙·같은 라벨 모드·같은 `DiagramToolShell`(하단 의견)** 을 재사용한다.
